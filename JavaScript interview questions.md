# JavaScript Interview Questions

## Basic JavaScript Questions
1. What are the different data types in JavaScript?
2. What is the difference between `let`, `const`, and `var`?
3. How does `null` differ from `undefined`?
4. What are template literals in JavaScript?
5. Explain the difference between `==` and `===`.
6. What is the purpose of the `typeof` operator?
7. How do you create a function in JavaScript?
8. What is an arrow function, and how is it different from a regular function?
9. How can you convert a string to a number in JavaScript?
10. What are truthy and falsy values?

## Intermediate JavaScript Questions
11. What is the difference between function declaration and function expression?
12. What is the difference between synchronous and asynchronous JavaScript?
13. Explain event delegation in JavaScript.
14. What is the purpose of the `this` keyword?
15. How do closures work in JavaScript?
16. Explain the difference between `map()`, `filter()`, and `forEach()`.
17. What is the purpose of the `spread` operator (`...`)?
18. How does the JavaScript event loop work?
19. What is the difference between `localStorage`, `sessionStorage`, and `cookies`?
20. How do promises work in JavaScript?

## Advanced JavaScript Questions
21. What is the difference between deep copy and shallow copy in JavaScript?
22. How does `async/await` work?
23. What is the difference between `call()`, `apply()`, and `bind()`?
24. How does JavaScript handle memory management?
25. What are WebSockets, and how do they work?
26. Explain the concept of **hoisting** in JavaScript.
27. What are **generator functions**, and when would you use them?
28. What are **prototypes**, and how does JavaScript implement inheritance?
29. What is **debouncing** and **throttling**, and how are they used?
30. What are WeakMap and WeakSet in JavaScript?

## Bonus: JavaScript Coding Challenges
1. Write a function to check if a string is a palindrome.
2. Write a function to find the largest number in an array.
3. Implement a function that removes duplicates from an array.
4. Write a function to reverse a string without using `.reverse()`.
5. Implement a simple **debounce function**.
